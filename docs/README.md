# Documentación — FerreControl

Proyecto formativo SENA (Tecnólogo en Análisis y Desarrollo de Software).
Sistema simulado de ERP/POS para ferreterías.

Esta documentación está organizada en las cinco fases habituales de un
proyecto de software formativo. Cada carpeta corresponde a una fase y
contiene los documentos que la sustentan:

| Fase | Carpeta | Contenido |
|---|---|---|
| 1. Análisis | `01-analisis/` | Requerimientos funcionales/no funcionales, alcance, actores, casos de uso |
| 2. Diseño | `02-diseno/` | Diagrama de clases, diagrama Entidad-Relación, arquitectura del sistema |
| 3. Desarrollo | `03-desarrollo/` | Manual técnico: stack, estructura del código, cómo levantar cada módulo |
| 4. Pruebas | `04-pruebas/` | Plan y casos de prueba, con estado real (aprobado/pendiente) |
| 5. Despliegue | `05-despliegue/` | Manual de usuario y manual de despliegue |

## Nota importante sobre esta documentación

Este material describe el sistema **tal como quedó construido** al momento de
escribirlo (backend con Express + PostgreSQL, frontend con React + Vite,
autenticación JWT). Los formatos de fase, plantillas de caso de uso y
nomenclatura siguen la práctica general de ingeniería de software — no un
formato oficial descargado del SENA, porque no tengo acceso a la guía de
aprendizaje específica de tu ficha (3235887). Antes de entregar, compara la
estructura de estas carpetas contra la guía o rúbrica que te haya dado tu
instructor y ajusta nombres/secciones si exige un formato distinto.
